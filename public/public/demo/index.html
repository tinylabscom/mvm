mvm wasm sandbox demo

A live in-browser governance sandbox. The wasm bundle is built from the same mvm-contract code the host uses for egress decisions and placeholder substitution. This page demonstrates policy, substitution, and audit-chain verification — not an isolation boundary.

Built from web/mvm-demo/ over mvm-contract. The browser is the wasm engine; the host WasmBackend is not exercised. Egress decision, placeholder substitution, host-is-bound, audit signing, and chain verification are the same code the host runs. The Run real WASI fixture button executes a tiny compiled wasm32-wasip1 module in a Web Worker, with the same mvm:egress host import the Firecracker/libkrun/HVF wasm backend provides.
