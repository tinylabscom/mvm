Run this machine from the CLI

      

        The browser Worker boots the same kernel/rootfs artifact that
        mvmctl machine run will accept once the WebLinux CLI
        surface lands. The intended command is:
      

      
mvmctl machine run --hypervisor web-linux \
  --kernel pack/kernel.img \
  --rootfs pack/rootfs.bin \
  --memory 512M --cpus 2

      

        The artifact is a kernel + block-rootfs pair, so the CLI surface uses
        --rootfs rather than --initrd. Until the
        native WebLinux path is wired, the equivalent raw QEMU invocation is
        used for the smoke test.
