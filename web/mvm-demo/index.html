mvm browser-tier microVM

Launch an mvm-defined microVM inside a WebAssembly sandbox. The same NetworkPolicy, authority, and audit semantics the host uses are enforced here by the browser's wasm engine instead of host wasmtime.

Launch config

Equivalent CLI: 
mvmctl up browser-vm --image mvm-demo-guest:latest --memory 128 --cpus 1

Console

root@mvm:~#
Tip: click the console to type. ↑/↓ history, Tab completion, Ctrl+C interrupt, Ctrl+L clear.

Audit chain

Each launch, stop, allow, and deny event is signed with the demo Ed25519 key. The chain can be verified with the same verify_audit_chain_bytes code the host uses.

—
Built from web/mvm-demo/ over mvm-contract. This is a browser-tier sandbox: it enforces mvm's constraints, but it is not a hardware-virtualized microVM and does not run host wasmtime.
