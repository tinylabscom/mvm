> **For agentic workers:** keep the checkboxes current. The last unchecked item is the current blocker.

**Status:** COMPLETE

**Goal:** Finish the port-handler registry refactor as a production-facing change rather than a code-only cleanup: replace the 5 ms backstop with readiness-driven host I/O, prove the runtime path with live validation, and keep the repo status documents aligned with reality.

**Architecture:** The vsock host-I/O thread maintains a dynamic readiness set derived from the active bridges themselves. Listeners and readable-relevant streams are registered with `mio::Poll`; topology changes wake the I/O thread so it can resync its fd set without relying on periodic polling. Host-initiated sockets are only registered once the guest has accepted them, which avoids a level-triggered busy loop on buffered pre-accept bytes.
