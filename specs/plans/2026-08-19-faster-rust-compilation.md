## Goal

Apply the useful parts of the referenced faster-compilation workflow without
weakening release artifacts, panic-unwinding tests, stable/MSRV compatibility,
or the repository's host/builder execution boundary.

## Measured baseline

Cold `mvm-contract` dev builds on the same Apple Silicon host and isolated
target directories:

| Configuration | Wall time |
|---|---:|
| Rust 1.96.0 + LLVM | 172.14s |
| nightly-2026-08-08 + Cranelift + 8 frontend threads | 66.48s |

The candidate is 61.4% faster for this representative crate. The workspace
already used `debug = "line-tables-only"` for both dev and test profiles and
used `lld` on Linux, so those recommendations required no new change.
