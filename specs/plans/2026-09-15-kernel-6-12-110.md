## Source verification

The upstream archive SHA-256 is
`8cee19e1839bb6ff4d5254d761933ae6ab670492d5ed030e09a80538320d5c4c`,
which converts to the Nix SRI hash
`sha256-jO4Z4YObtv9NUlTXYZM65qtnBJLV7QMOCagFODINXEw=`.

The downloaded archive matches kernel.org's clearsigned `v6.x/sha256sums.asc`
manifest. The detached signature over the uncompressed archive independently
verifies against release key fingerprint
`647F 2865 4894 E3BD 4571 99BE 38DB BDC8 6092 693E`.

The resolved aarch64 workload config replaces `CONFIG_GENERIC_PTDUMP` with
`CONFIG_ARCH_HAS_PTDUMP` and adds
`CONFIG_MHP_DEFAULT_ONLINE_TYPE_OFFLINE`, the explicit default for the existing
memory-hotplug family. That produces one net additional built-in symbol, so the
tight aarch64 ratchet moves from its measured 959 to 960; x86_64 remains 917.

## Rollout

This repository pin does not modify already-running VMs. Locally managed VMs
move with `mvmctl vm rekernel`; fleet rollout remains owned by mvmd.
